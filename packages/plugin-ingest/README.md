# @chkit/plugin-ingest

This compatibility package re-exports the public API and testing helpers from `@chkit/plugin-sync`. Use [chkit](https://www.npmjs.com/package/chkit) with the Sync plugin for new projects.

See the [Sync migration guide](https://chkit.obsessiondb.com/plugins/sync/#upgrade-from-the-ingest-plugin) for existing projects.

`chkit codegen`, `chkit obsessiondb` and `chkit plugin` never take `-h` / `--help` as the value of
`--config`: `--config --help --config=x.py` shows the help instead of running the plugin command
with `x.py`, and next to `--help-plugins` a `--config` with no value is `Missing value for
--config` on every command, as in TS (#619).

`chkit codegen`, `chkit obsessiondb` and `chkit plugin` never take `-h` / `--help` as the value of
`--config`: `--config -h --config=x.py` shows the help instead of running the plugin command with
`x.py`. As in TS, a `--config` with no value is `Missing value for --config` before the help of
`codegen`, `obsessiondb` and `pull` (plugin commands in TS) and next to `--help-plugins`, while the
built-in commands and `plugin` show their help; a `-c` that is another flag's value
(`generate --name -c`) is not `--config` (#619).

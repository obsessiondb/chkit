A `chkit plugin backfill` chunk into a `Distributed` table is no longer marked done while its rows are still queued on the initiator: every chunk INSERT now runs with `distributed_foreground_insert = 1` and `materialized_views_ignore_errors = 0`, so it returns only once its rows reached the shards and a materialized view that fails to write fails the chunk; `insertSettings` that change either (or `insert_distributed_sync`) are refused.

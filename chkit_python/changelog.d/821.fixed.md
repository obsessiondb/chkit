A `chkit plugin backfill` chunk into a `Distributed` table is no longer marked done while its rows are still queued: chunk INSERTs default to `distributed_foreground_insert = 1` and `materialized_views_ignore_errors = 0`. `insertSettings` can now override those two defaults (or `insert_distributed_sync`), with a warning naming the guarantee that is off; the other pinned settings are still refused.

Every `chkit plugin backfill` chunk INSERT now runs with `allow_experimental_parallel_reading_from_replicas = 0` (`enable_parallel_replicas` from 24.10 on), `parallel_distributed_insert_select = 0` and full query logging, so a failed chunk is never replayed on top of rows its replicas or shards wrote; `insertSettings` that set one of those or an alias (such as `enable_parallel_replicas`) to another value are refused, and a user who may not change them gets an error before anything is sent.

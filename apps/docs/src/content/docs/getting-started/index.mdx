chkit manages ClickHouse schemas and migrations in TypeScript and Python: define tables in code, generate SQL, review the migration, and apply it to the database.

Start with the first-schema tutorial to learn the workflow from an empty folder, or add chkit to an existing application.

:::note[Python support is in beta]
Install [chkit-py](/python/overview/) with `pip install chkit-py`. Use the Python tabs in the schema and CLI reference pages. Its API and CLI behavior may change between releases.
:::

Already have tables in ClickHouse? Use [schema introspection](/plugins/pull/) to import their definitions before planning changes. For typed application code, add [row model generation](/plugins/codegen/) after defining the schema.

## Prerequisites

Choose the runtime for the project's language and a database target:

- Node.js 22+ or Bun 1.3.5+ for TypeScript, or Python 3.11+ for Python
- A ClickHouse 24.x or newer endpoint (see [compatibility](/guides/clickhouse-compatibility/)), or a free ObsessionDB dev instance claimed during setup. For a direct connection, set `CLICKHOUSE_URL` and any required `CLICKHOUSE_USER` / `CLICKHOUSE_PASSWORD` values.
